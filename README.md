# OSI Model and Network Traffic Analysis Using Wireshark

## Overview

This project explores network communication through practical packet analysis using Wireshark. It focuses on understanding the OSI model and examining how common network protocols operate in real-world traffic.

## Objectives

- Understand the seven layers of the OSI model.
- Inspect packet headers and network addresses.
- Analyze DNS queries and domain name resolution.
- Examine HTTP requests and their headers.
- Practice using Wireshark display filters.
- Build practical networking knowledge relevant to cybersecurity and SOC operations.

## Tools Used

- Wireshark
- Npcap
- Windows 11

## Key Activities

- Captured and inspected network traffic.
- Examined source and destination IP addresses, MAC addresses, and port numbers.
- Investigated DNS query packets.
- Analyzed an HTTP GET request.
- Used display filters to isolate and investigate specific protocols.
